https://github.com/d3/d3
Language: JavaScript 
Found this repo that fits the definition of creative coding. It can be categorized into data art and D3 has built-in D3 force feature which can be utilized to charge forces (repulsion/attraction), collision forces, and spring forces to organically simulate complex data relationships and network topologies.

https://github.com/keijiro/Skinner
Language: C# and HLSL
Found this repo that fits the definition of creative coding. It creates special effects with Skinned Mesh in Unity. It demonstrate how to take standard 3D meshes and dissolve them into millions of audio-reactive, physics-driven particles in real-time. Also, it uses special replacement shaders to convert vertex positions into GPU-friendly data.

https://github.com/mrdoob/three.js
Language: JavaScript / WebGL
Found this repo that fits the definition of creative coding. It represents traditional text-based creative coding, where developers write JavaScript to dictate spatial geometry, materials, lighting, and rendering loops. While both p5.js and Three.js are JavaScript libraries used for creative coding, they operate on completely different architectural paradigms. If p5.js is a 2D sketchbook, Three.js is a 3D film set. It relies on a hierarchical scene graph, meaning you construct a scene, place a camera, establish light sources, and render 3D meshes. It elevates standard web development into creative coding by allowing developers to build immersive, interactive isometric workspaces and spatial environments directly in the browser.

https://github.com/EaminC/Cyber-Jellyfish
Language: Python
Found this repo that fits the definition of creative coding. Unlike the previous repositories (which are massive frameworks and libraries), this project is a direct application of creative coding principles. It uses code not to solve a utilitarian software problem, but to generate an organic, geometric cyber jellyfish.
